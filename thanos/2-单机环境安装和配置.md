# 第2章：单机环境安装和配置

## 2.1 环境准备和依赖检查

### 2.1.1 系统要求

**最低硬件配置**：
- CPU：2核心
- 内存：4GB
- 磁盘：50GB可用空间
- 网络：稳定的互联网连接

**推荐硬件配置**：
- CPU：4核心
- 内存：8GB
- 磁盘：100GB可用空间（SSD推荐）
- 网络：千兆网络

### 2.1.2 软件依赖

**必需软件**：
- Linux/Unix操作系统（Ubuntu 18.04+，CentOS 7+）
- Docker 20.10+（容器化部署）
- Prometheus 2.0+（数据源）

**可选软件**：
- MinIO（本地对象存储模拟）
- Grafana 7.0+（数据可视化）
- Nginx（反向代理）

### 2.1.3 环境检查脚本

创建环境检查脚本 `check_environment.sh`：

```bash
#!/bin/bash

echo "=== 环境依赖检查 ==="

# 检查操作系统
if [[ "$OSTYPE" == "linux-gnu"* ]]; then
    echo "✓ 操作系统: Linux"
    cat /etc/os-release | grep PRETTY_NAME
else
    echo "✗ 不支持的OS类型: $OSTYPE"
    exit 1
fi

# 检查Docker
echo -n "检查Docker..."
if command -v docker &> /dev/null; then
    echo "✓ 已安装"
    docker --version
else
    echo "✗ 未安装"
fi

# 检查Prometheus
echo -n "检查Prometheus..."
if command -v prometheus &> /dev/null; then
    echo "✓ 已安装"
    prometheus --version
else
    echo "✗ 未安装（可选）"
fi

# 检查磁盘空间
echo -n "检查磁盘空间..."
available=$(df / | awk 'NR==2 {print $4}')
if [ $available -gt 50000000 ]; then
    echo "✓ 充足 ($(($available/1024/1024))GB可用)"
else
    echo "✗ 不足 ($(($available/1024/1024))GB可用)"
fi

# 检查内存
echo -n "检查内存..."
mem_total=$(free -m | awk 'NR==2{print $2}')
if [ $mem_total -gt 2000 ]; then
    echo "✓ 充足 (${mem_total}MB)"
else
    echo "⚠ 较低 (${mem_total}MB)"
fi

echo "=== 环境检查完成 ==="
```

## 2.2 二进制安装方法

### 2.2.1 下载Thanos二进制文件

**方法一：直接下载**
```bash
# 创建安装目录
mkdir -p /opt/thanos
cd /opt/thanos

# 下载最新版本（替换为实际版本号）
THANOS_VERSION="0.32.0"
wget https://github.com/thanos-io/thanos/releases/download/v${THANOS_VERSION}/thanos-${THANOS_VERSION}.linux-amd64.tar.gz

# 解压
tar -xzf thanos-${THANOS_VERSION}.linux-amd64.tar.gz

# 创建软链接
ln -s thanos-${THANOS_VERSION}.linux-amd64/thanos /usr/local/bin/thanos

# 验证安装
thanos --version
```

**方法二：使用包管理器**
```bash
# 对于Ubuntu/Debian
wget -q -O - https://apt.thanos.io/thanos-io.gpg.key | sudo apt-key add -
echo "deb https://apt.thanos.io/ thanos main" | sudo tee /etc/apt/sources.list.d/thanos.list
sudo apt update
sudo apt install thanos

# 对于CentOS/RHEL
sudo yum install -y yum-utils
sudo yum-config-manager --add-repo https://yum.thanos.io/thanos.repo
sudo yum install thanos
```

### 2.2.2 安装验证脚本

创建验证脚本 `verify_installation.sh`：

```bash
#!/bin/bash

echo "=== Thanos安装验证 ==="

# 检查thanos命令
if command -v thanos &> /dev/null; then
    echo "✓ Thanos命令可用"
    thanos --version
else
    echo "✗ Thanos命令不可用"
    exit 1
fi

# 检查组件
components=("query" "sidecar" "store" "compact" "rule")
for component in "${components[@]}"; do
    echo -n "检查${component}组件..."
    if thanos ${component} --help &> /dev/null; then
        echo "✓ 正常"
    else
        echo "✗ 异常"
    fi
done

echo "=== 安装验证完成 ==="
```

## 2.3 Docker容器化部署

### 2.3.1 Docker安装配置

**安装Docker**：
```bash
# 安装Docker CE
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 启动Docker服务
sudo systemctl enable docker
sudo systemctl start docker

# 添加用户到docker组
sudo usermod -aG docker $USER
```

**配置Docker镜像加速**：
```bash
# 创建Docker配置目录
sudo mkdir -p /etc/docker

# 配置镜像加速器
sudo tee /etc/docker/daemon.json <<EOF
{
  "registry-mirrors": [
    "https://docker.mirrors.ustc.edu.cn",
    "https://hub-mirror.c.163.com"
  ]
}
EOF

# 重启Docker
sudo systemctl daemon-reload
sudo systemctl restart docker
```

### 2.3.2 使用Docker Compose部署

创建 `docker-compose.yml` 文件：

```yaml
version: '3.8'

services:
  # MinIO对象存储（模拟S3）
  minio:
    image: minio/minio:latest
    container_name: thanos-minio
    command: server /data --console-address ":9001"
    environment:
      MINIO_ROOT_USER: thanos
      MINIO_ROOT_PASSWORD: thanos123
    ports:
      - "9000:9000"  # API端口
      - "9001:9001"  # 控制台端口
    volumes:
      - minio_data:/data
    networks:
      - thanos-net

  # Prometheus实例
  prometheus:
    image: prom/prometheus:latest
    container_name: thanos-prometheus
    command:
      - '--config.file=/etc/prometheus/prometheus.yml'
      - '--storage.tsdb.path=/prometheus'
      - '--web.console.libraries=/etc/prometheus/console_libraries'
      - '--web.console.templates=/etc/prometheus/consoles'
      - '--web.enable-lifecycle'
    ports:
      - "9090:9090"
    volumes:
      - ./config/prometheus.yml:/etc/prometheus/prometheus.yml:ro
      - prometheus_data:/prometheus
    networks:
      - thanos-net

  # Thanos Sidecar
  thanos-sidecar:
    image: thanosio/thanos:latest
    container_name: thanos-sidecar
    command:
      - sidecar
      - --http-address=0.0.0.0:19191
      - --grpc-address=0.0.0.0:19090
      - --prometheus.url=http://prometheus:9090
      - --tsdb.path=/prometheus
      - --objstore.config-file=/etc/thanos/minio-bucket.yaml
    ports:
      - "19191:19191"
      - "19090:19090"
    volumes:
      - ./config/minio-bucket.yaml:/etc/thanos/minio-bucket.yaml:ro
      - prometheus_data:/prometheus:ro
    depends_on:
      - prometheus
      - minio
    networks:
      - thanos-net

  # Thanos Query
  thanos-query:
    image: thanosio/thanos:latest
    container_name: thanos-query
    command:
      - query
      - --http-address=0.0.0.0:19192
      - --grpc-address=0.0.0.0:19091
      - --query.replica-label=replica
      - --store=thanos-sidecar:19090
    ports:
      - "19192:19192"
    depends_on:
      - thanos-sidecar
    networks:
      - thanos-net

volumes:
  minio_data:
  prometheus_data:

networks:
  thanos-net:
    driver: bridge
```

### 2.4.2 服务验证脚本

创建验证脚本 `verify_services.sh`：

```bash
#!/bin/bash

echo "=== 服务状态检查 ==="

# 检查Docker容器状态
services=("minio" "prometheus" "thanos-sidecar" "thanos-query")

for service in "${services[@]}"; do
    echo -n "检查${service}..."
    status=$(docker inspect --format='{{.State.Status}}' thanos-${service} 2>/dev/null)
    if [ "$status" = "running" ]; then
        echo "✓ 运行中"
    else
        echo "✗ 异常 ($status)"
    fi
done

echo ""
echo "=== 端口检查 ==="

# 检查端口监听
ports=("9000" "9090" "19191" "19192")
for port in "${ports[@]}"; do
    echo -n "检查端口${port}..."
    if netstat -tuln | grep ":${port} " &> /dev/null; then
        echo "✓ 监听中"
    else
        echo "✗ 未监听"
    fi
done

echo ""
echo "=== API接口测试 ==="

# 测试Prometheus API
echo -n "测试Prometheus..."
if curl -s http://localhost:9090/api/v1/query?query=up | grep -q "success"; then
    echo "✓ 正常"
else
    echo "✗ 异常"
fi

# 测试Thanos Query API
echo -n "测试Thanos Query..."
if curl -s http://localhost:19192/api/v1/query?query=up | grep -q "success"; then
    echo "✓ 正常"
else
    echo "✗ 异常"
fi

# 测试MinIO控制台
echo -n "测试MinIO控制台..."
if curl -s http://localhost:9001/minio/health/live | grep -q "OK"; then
    echo "✓ 正常"
else
    echo "✗ 异常"
fi

echo "=== 服务验证完成 ==="
```

### 2.4.3 数据上传验证

创建数据验证脚本 `verify_data_upload.sh`：

```bash
#!/bin/bash

echo "=== 数据上传验证 ==="

# 等待数据上传（首次启动需要时间）
echo "等待30秒让数据上传完成..."
sleep 30

# 检查对象存储中的块文件
echo "检查MinIO中的块文件..."
if docker exec thanos-minio mc ls local/thanos/ | grep -q "chunks"; then
    echo "✓ 数据块已上传到对象存储"
else
    echo "⚠ 未发现数据块，可能需要更多时间"
fi

# 查询数据验证
echo "通过Thanos Query查询数据..."
response=$(curl -s "http://localhost:19192/api/v1/query?query=up")
if echo "$response" | grep -q "metric"; then
    echo "✓ 查询成功，数据正常"
    echo "返回的指标数量: $(echo "$response" | jq '.data.result | length')"
else
    echo "✗ 查询失败"
fi

echo "=== 数据验证完成 ==="
```

## 2.5 故障排查和常见问题

### 2.5.1 常见问题解决

**问题1：端口冲突**
```bash
# 检查端口占用
netstat -tuln | grep <端口号>

# 修改docker-compose.yml中的端口映射
ports:
  - "新端口:容器端口"
```

**问题2：权限不足**
```bash
# 检查Docker权限
docker ps

# 添加用户到docker组
sudo usermod -aG docker $USER
newgrp docker
```

**问题3：存储空间不足**
```bash
# 检查磁盘使用情况
df -h

# 清理Docker镜像和容器
docker system prune -a
```

### 2.5.2 日志查看和调试

docker-compose logs
