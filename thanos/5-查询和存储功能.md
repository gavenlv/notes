# 第5章：查询和存储功能

## 5.1 全局查询语法和示例

### 5.1.1 PromQL扩展语法

Thanos完全兼容Prometheus的PromQL查询语言，并在此基础上提供扩展功能：

**基础查询语法**：
```promql
# 即时查询
up{job="prometheus"}

# 范围查询
rate(http_requests_total[5m])

# 聚合查询
sum by (instance) (rate(node_cpu_seconds_total[5m]))

# 数学运算
node_memory_MemTotal_bytes - node_memory_MemFree_bytes
```

**Thanos扩展功能**：
```promql
# 跨集群查询（自动聚合）
sum by (cluster) (up)

# 时间范围扩展查询
up{job="prometheus"} offset 1w

# 多数据源联合查询
label_join(up{cluster="a"}, "source", "", "cluster-a") or 
label_join(up{cluster="b"}, "source", "", "cluster-b")
```

### 5.1.2 高级查询示例

**多集群监控查询**：
```promql
# 监控所有集群的CPU使用率
100 - (avg by (cluster) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)

# 跨集群服务可用性监控
avg by (service) (
  label_replace(up{cluster="prod"}, "env", "production", "", "") or
  label_replace(up{cluster="staging"}, "env", "staging", "", "")
)

# 集群间数据对比
(
  sum(rate(http_requests_total{cluster="us-east"}[5m])) /
  sum(rate(http_requests_total{cluster="us-west"}[5m]))
) * 100
```

**长期趋势分析**：
```promql
# 30天内存使用趋势
avg_over_time(
  (node_memory_MemTotal_bytes - node_memory_MemFree_bytes) 
  [30d:1h]
)

# 周环比增长分析
(
  sum(rate(http_requests_total[1w])) -
  sum(rate(http_requests_total[1w] offset 1w))
) / sum(rate(http_requests_total[1w] offset 1w)) * 100
```


## 5.3 对象存储配置

### 5.3.1 AWS S3配置

**生产环境S3配置**：
```yaml
# s3-production.yaml
type: S3
config:
  bucket: "thanos-monitoring-prod"
  endpoint: "s3.amazonaws.com"
  region: "us-east-1"
  access_key: "${AWS_ACCESS_KEY_ID}"
  secret_key: "${AWS_SECRET_ACCESS_KEY}"
  
  # 安全配置
  insecure: false
  signature_version2: false
  
  # 存储类配置
  sse_config:
    type: "SSE-S3"
    
  # 传输优化
  part_size: 134217728  # 128MB
  
  # HTTP配置
  http_config:
    idle_conn_timeout: 90s
    response_header_timeout: 2m
    tls_config:
      insecure_skip_verify: false
      
  # 调试配置
  trace:
    enable: false
    
  # 列表操作配置
  list_objects_version: ""
  
  # 存储桶策略（示例）
  bucket_lookup_type: "auto"
```

## 5.4 数据保留策略

### 5.4.1 分层保留策略

**时间分层保留**：
```yaml
# retention-policy.yaml
retention:
  # 原始数据保留策略
  raw:
    # 热数据：保留7天（本地SSD）
    hot: 7d
    
    # 温数据：保留30天（标准存储）
    warm: 30d
    
    # 冷数据：保留1年（低频存储）
    cold: 365d
    
  # 降采样数据保留策略
  downsampled:
    # 5分钟精度：保留6个月
    5m: 180d
    
    # 1小时精度：保留2年
    1h: 730d
    
    # 1天精度：永久保留
    1d: 0d
```

**成本优化配置**：
```yaml

retention:
```

## 5.5 查询性能优化

### 5.5.1 查询缓存配置

**多级缓存策略**：
```yaml
# query-cache.yaml
query:
  # 内存缓存
  in_memory_cache:
    enabled: true
    max_size: "4GB"
    validity: 1h
    
  # Redis缓存（分布式缓存）
  redis_cache:
    enabled: true
    address: "redis://thanos-cache:6379"
    password: "${REDIS_PASSWORD}"
    database: 0
    pool_size: 10
    
  # 查询结果缓存
  result_cache:
    enabled: true
    max_size: "1GB"
    validity: 30m
    
  # 元数据缓存
  metadata_cache:
    enabled: true
    max_size: "512MB"
    validity: 24h
```

### 5.5.2 查询优化技巧

**高效查询模式**：
```promql
# 避免全量扫描（使用标签过滤）
# 不推荐：rate(http_requests_total[5m])
# 推荐：rate(http_requests_total{job="api"}[5m])

# 使用子查询优化
# 不推荐：avg_over_time(rate(http_requests_total[5m])[1h:])
# 推荐：avg_over_time(rate(http_requests_total[5m])[1h:5m])

# 合理使用聚合
# 不推荐：sum(rate(http_requests_total[5m])) by (instance)
# 推荐：sum by (instance) (rate(http_requests_total[5m]))

# 避免不必要的数学运算
# 不推荐：100 - (avg(rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)
# 推荐：100 * avg(rate(node_cpu_seconds_total{mode!="idle"}[5m]))
```

## 5.7 监控和告警配置

### 5.7.1 查询性能监控

**关键性能指标**：
```yaml
groups:
- name: thanos-query-performance
  rules:
  - record: thanos_query_p99_latency
    expr: histogram_quantile(0.99, thanos_query_request_duration_seconds_bucket)
    
  - record: thanos_query_success_rate
    expr: sum(rate(thanos_query_requests_total{status=~"2.."}[5m])) / sum(rate(thanos_query_requests_total[5m]))
    
  - record: thanos_store_cache_hit_ratio
    expr: rate(thanos_store_cached_series_hits_total[5m]) / rate(thanos_store_cached_series_requests_total[5m])
```

### 5.7.2 存储健康监控

**存储健康告警**：
```yaml
groups:
- name: thanos-storage-health
  rules:
  - alert: ThanosStorageHighLatency
    expr: histogram_quantile(0.95, thanos_store_bucket_operation_duration_seconds_bucket{operation="get"}) > 5
    for: 5m
    labels:
      severity: warning
    annotations:
      summary: "Thanos存储操作高延迟"
      description: "存储get操作P95延迟超过5秒"
      
  - alert: ThanosStorageErrorRateHigh
    expr: rate(thanos_store_bucket_operations_total{status!~"2.."}[5m]) / rate(thanos_store_bucket_operations_total[5m]) > 0.05
    for: 10m
    labels:
      severity: critical
    annotations:
      summary: "Thanos存储错误率高"
      description: "存储操作错误率超过5%"
      
  - alert: ThanosQueryCacheHitRateLow
    expr: rate(thanos_query_cache_hits_total[5m]) / rate(thanos_query_cache_requests_total[5m]) < 0.7
    for: 15m
    labels:
      severity: warning
    annotations:
      summary: "Thanos查询缓存命中率低"
      description: "查询缓存命中率低于70%"
```
