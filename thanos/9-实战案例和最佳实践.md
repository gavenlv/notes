## 9.5 故障排除和问题诊断

### 9.5.1 常见问题诊断

#### 查询性能问题

```bash
#!/bin/bash
# query-troubleshooting.sh - 查询性能问题诊断

echo "开始查询性能问题诊断..."

# 检查查询延迟
echo "1. 检查查询延迟..."
curl -s "http://thanos-query:10902/api/v1/query?query=histogram_quantile(0.95, rate(thanos_query_api_call_duration_seconds_bucket[5m]))" | jq '.data.result[0].value[1]'

# 检查并发查询数
echo "2. 检查并发查询数..."
curl -s "http://thanos-query:10902/api/v1/query?query=thanos_query_concurrent_current" | jq '.data.result[0].value[1]'

# 检查缓存命中率
echo "3. 检查缓存命中率..."
HITS=$(curl -s "http://thanos-query:10902/api/v1/query?query=thanos_cache_hits_total" | jq '.data.result[0].value[1]' | tr -d '"')
MISSES=$(curl -s "http://thanos-query:10902/api/v1/query?query=thanos_cache_misses_total" | jq '.data.result[0].value[1]' | tr -d '"')

if [ "$HITS" -gt 0 ] && [ "$MISSES" -gt 0 ]; then
    HIT_RATE=$(echo "scale=2; $HITS / ($HITS + $MISSES) * 100" | bc)
    echo "缓存命中率: ${HIT_RATE}%"
fi

# 检查存储组件状态
echo "4. 检查存储组件状态..."
curl -s "http://thanos-query:10902/api/v1/stores" | jq '.data.stores[] | {name: .name, minTime: .minTime, maxTime: .maxTime, labelSets: .labelSets}'

echo "诊断完成!"
```
