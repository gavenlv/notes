# 可观测性技术栈详细说明

## 1. 指标监控技术栈

### 1.1 Prometheus

#### 核心特性
- **多维数据模型**: 支持标签（labels）的多维时间序列数据
- **强大的查询语言**: PromQL提供灵活的查询能力
- **不依赖分布式存储**: 单节点可靠性
- **基于HTTP的拉取模式**: 主动采集指标数据
- **支持服务发现**: 自动发现监控目标

#### 架构组件
```yaml
Prometheus Server:
  - 数据采集和存储
  - 规则评估和告警
  - HTTP API和查询界面

Exporters:
  - Node Exporter: 系统指标
  - cAdvisor: 容器指标
  - JMX Exporter: Java应用指标
  - Blackbox Exporter: 网络探测

Pushgateway:
  - 支持短期任务指标推送
  - 批处理作业监控

Alertmanager:
  - 告警去重和分组
  - 静默和抑制机制
  - 多通知渠道支持
```

#### 配置示例
```yaml
# prometheus.yml
global:
  scrape_interval: 15s
  evaluation_interval: 15s

rule_files:
  - "alert_rules.yml"

scrape_configs:
  - job_name: 'prometheus'
    static_configs:
      - targets: ['localhost:9090']
  
  - job_name: 'node'
    static_configs:
      - targets: ['node-exporter:9100']
```

### 1.2 Thanos / Cortex

#### Thanos 架构
```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  Prometheus  │    │   Thanos    │    │   Thanos    │
│   实例A      │◄──►│   Sidecar   │◄──►│    Query    │
└─────────────┘    └─────────────┘    └─────────────┘
                         │                    │
                         ▼                    ▼
                 ┌─────────────┐    ┌─────────────┐
                 │  对象存储   │    │   Grafana   │
                 │ (S3/GCS)    │    │             │
                 └─────────────┘    └─────────────┘
```

#### 核心优势
- **长期存储**: 支持对象存储（S3、GCS）
- **全局视图**: 统一查询多个Prometheus实例
- **数据压缩**: 降低存储成本
- **高可用性**: 消除单点故障

## 2. 日志管理技术栈

### 2.1 Loki

#### 架构设计
```yaml
Loki Components:
  - Distributor: 日志接收和分发
  - Ingester: 日志索引和存储
  - Querier: 日志查询处理
  - Query Frontend: 查询前端优化

存储后端:
  - Index: 使用BoltDB或Cassandra
  - Chunks: 使用对象存储或本地文件系统
```

#### 核心特性
- **索引与存储分离**: 降低存储成本
- **标签索引**: 类似Prometheus的标签系统
- **LogQL查询语言**: 强大的日志查询能力
- **云原生设计**: 适合Kubernetes环境

#### 配置示例
```yaml
# loki-config.yaml
auth_enabled: false

server:
  http_listen_port: 3100

ingester:
  lifecycler:
    address: 127.0.0.1
    ring:
      kvstore:
        store: inmemory
      replication_factor: 1
  chunk_idle_period: 1h
  max_chunk_age: 1h

schema_config:
  configs:
    - from: 2020-10-24
      store: boltdb
      object_store: filesystem
      schema: v11
      index:
        prefix: index_
        period: 168h

storage_config:
  boltdb:
    directory: /loki/index
  filesystem:
    directory: /loki/chunks
```

## 4. 数据采集技术栈

### 4.1 Fluentd

#### 架构设计
```yaml
输入插件:
  - tail: 文件尾随
  - http: HTTP接收
  - syslog: 系统日志
  - tcp/udp: 网络协议

过滤插件:
  - parser: 日志解析
  - record_transformer: 记录转换
  - grep: 日志过滤

输出插件:
  - elasticsearch: ES输出
  - loki: Loki输出
  - kafka: Kafka输出
  - file: 文件输出
```

#### 配置示例
```xml
<source>
  @type tail
  path /var/log/*.log
  pos_file /var/log/fluentd.pos
  tag system.*
  format none
</source>

<filter system.**>
  @type parser
  format /^(?<time>\S+) (?<level>\S+) (?<message>.*)$/
  key_name message
</filter>

<match system.**>
  @type loki
  url http://loki:3100
  username ""
  password ""
  extra_labels {"job":"fluentd"}
</match>
```

### 4.2 Vector

#### 核心特性
- **高性能**: Rust编写，性能优异
- **统一数据模型**: 支持指标、日志、追踪
- **声明式配置**: YAML配置，易于管理
- **云原生**: 适合现代基础设施

#### 配置示例
```yaml
# vector.toml
[sources.syslog]
type = "file"
include = ["/var/log/syslog"]

[transforms.parse_syslog]
type = "regex_parser"
inputs = ["syslog"]
patterns = ["^(?P<timestamp>\\S+) (?P<host>\\S+) (?P<message>.*)$"]

[sinks.loki]
type = "loki"
inputs = ["parse_syslog"]
endpoint = "http://loki:3100"
labels = { "job" = "vector" }
```
