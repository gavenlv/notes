# 第7章：dbt高级特性与自定义操作

## 项目概述
本章演示dbt的高级特性和自定义操作，包括复杂宏开发、自定义物料化策略、钩子函数、包管理、性能优化等高级功能。

## 核心目录结构

```
chapter7/
├── README.md                    # 项目说明文档
├── dbt_project.yml              # 项目配置文件
├── profiles.yml                 # 数据库连接配置
├── models/                      # 数据模型
│   ├── advanced/               # 高级特性演示模型
│   ├── custom_materializations/ # 自定义物化策略
│   └── hooks/                  # 钩子函数演示
├── macros/                      # 高级宏定义
│   ├── complex/                # 复杂业务逻辑宏
│   ├── packages/               # 包管理相关宏
│   └── performance/            # 性能优化宏
├── tests/                       # 高级测试配置
│   ├── custom_tests/           # 自定义测试
│   └── integration/            # 集成测试
├── packages.yml                 # 包依赖配置
└── run_advanced.bat            # 运行脚本
```

## 运行步骤

### 1. 环境准备
```bash
# 安装dbt核心包
pip install dbt-core dbt-postgres

# 安装第三方包
dbt deps
```

### 2. 项目设置
```bash
# 验证配置
dbt debug

# 编译项目
dbt compile
```

### 3. 运行示例
```bash
# 运行高级特性演示
./run_advanced.bat

# 或手动运行特定功能
dbt run --select advanced.*
dbt test --select custom_tests.*
```

### 4. 查看结果
```bash
# 生成文档
dbt docs generate
dbt docs serve
```

## 关键概念演示

### 动态业务逻辑实现
演示如何根据业务规则动态生成SQL查询，适应变化的业务需求。

### 高级性能优化
展示分区策略、集群配置、资源限制等高级优化技术。

### 自定义扩展功能
实现自定义物料化策略和测试框架，扩展dbt核心功能。

### 企业级安全实践
演示数据脱敏、行级安全等企业级安全特性。

## 注意事项

1. **环境要求**：需要支持高级特性的数据库（如PostgreSQL 12+、Snowflake、BigQuery）
2. **权限配置**：部分高级功能需要数据库管理员权限
3. **性能考虑**：复杂宏和自定义操作可能影响运行性能
4. **测试覆盖**：建议为自定义功能编写完整的测试用例
