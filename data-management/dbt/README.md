# dbt (Data Build Tool) 从0入门到专家

## 学习路径概述

本系列教程将带您从零开始学习dbt，逐步掌握这个强大的数据转换工具。无论您是数据工程师、数据分析师还是数据科学家，都能通过本教程获得实用的dbt技能。

### 学习目标
- 理解dbt的核心概念和工作原理
- 掌握dbt项目的创建、配置和管理
- 学会使用dbt进行数据建模、测试和文档化
- 掌握dbt高级特性和最佳实践
- 能够独立完成dbt项目的部署和优化

### 学习建议

1. **循序渐进**：按照章节顺序学习，每个章节都有完整的代码示例
2. **动手实践**：每个章节都包含可运行的代码示例
3. **理解原理**：不仅要学会如何使用，更要理解为什么这样设计
4. **结合实际**：将学到的知识应用到实际项目中

### 前置知识

- 基本的SQL知识
- 对数据仓库概念有一定了解
- 熟悉命令行操作（可选）
- 了解版本控制（Git）基础（可选）

### 环境要求

- Python 3.7+
- dbt Core 或 dbt Cloud
- 支持的数据库（如PostgreSQL、Snowflake、BigQuery等）
