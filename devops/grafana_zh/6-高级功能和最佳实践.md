# 第6章：高级功能和最佳实践

## 6.1 插件系统扩展

Grafana的插件系统允许您扩展平台功能，集成第三方数据源、面板和应用。

### 6.1.1 插件类型概述

Grafana支持多种类型的插件：

- **数据源插件**: 连接新的数据源类型
- **面板插件**: 添加新的可视化组件
- **应用插件**: 提供完整的功能模块
- **数据转换插件**: 增强数据处理能力

### 6.1.2 插件管理

#### 安装插件

```bash
# 使用Grafana CLI安装插件
grafana-cli plugins install grafana-clock-panel
grafana-cli plugins install grafana-simple-json-datasource

# 安装社区插件
grafana-cli plugins install vonage-status-panel
grafana-cli plugins install flant-statusmap-panel

# 从URL安装插件
grafana-cli --pluginUrl https://example.com/plugin.zip plugins install custom-plugin
```

#### 插件配置

在`grafana.ini`中配置插件设置：

```ini
[plugins]
# 启用/禁用插件
enable_alpha = false
app_tls_skip_verify_insecure = false

# 允许未签名插件（开发环境）
allow_loading_unsigned_plugins = custom-datasource,custom-panel

# 插件目录
plugins = /var/lib/grafana/plugins
```

### 6.1.3 常用插件推荐

#### 数据源插件

- **PostgreSQL**: 增强的PostgreSQL数据源
- **MongoDB**: MongoDB数据源支持
- **Redis**: Redis监控数据源
- **AWS CloudWatch**: 深度集成AWS服务

#### 面板插件

- **Clock Panel**: 显示当前时间
- **Pie Chart Panel**: 饼图可视化
- **Worldmap Panel**: 地理数据可视化
- **Status Panel**: 服务状态显示

## 6.2 用户和权限管理

### 6.2.1 用户管理

Grafana支持多种用户管理方式：

#### 本地用户管理

```ini
[auth.anonymous]
# 匿名访问配置
enabled = false
org_name = Main Org.
org_role = Viewer

[auth.basic]
# 基础认证
enabled = true

[users]
# 用户配置
allow_sign_up = false
auto_assign_org = true
auto_assign_org_role = Viewer
```

#### 外部认证集成

```ini
[auth.generic_oauth]
# OAuth认证
enabled = true
name = OAuth
client_id = your-client-id
client_secret = your-client-secret
scopes = openid profile email
auth_url = https://oauth-provider.com/oauth/authorize
token_url = https://oauth-provider.com/oauth/token
api_url = https://oauth-provider.com/api/user

[auth.ldap]
# LDAP认证
enabled = true
config_file = /etc/grafana/ldap.toml
```

### 6.2.2 权限管理

#### 组织权限

```yaml
# 组织角色权限
组织管理员(Org Admin):
  - 管理用户和团队
  - 创建和管理数据源
  - 管理仪表板和文件夹
  - 配置告警规则

编辑器(Editor):
  - 创建和编辑仪表板
  - 创建告警规则
  - 查看数据源

查看者(Viewer):
  - 查看仪表板和数据
  - 无法进行修改操作
```

#### 团队管理

创建和管理团队：

```bash
# 使用API创建团队
curl -X POST http://localhost:3000/api/teams \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "infrastructure-team", "email": "infra@company.com"}'

# 添加用户到团队
curl -X POST http://localhost:3000/api/teams/1/members \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"userId": 2}'
```

## 6.3 性能优化和调优

### 6.3.1 数据库优化

#### PostgreSQL配置

对于生产环境，建议使用PostgreSQL替代SQLite：

```ini
[database]
type = postgres
host = 127.0.0.1:5432
name = grafana
user = grafana
password = your-password
ssl_mode = disable

# 连接池配置
max_idle_conn = 10
max_open_conn = 100
conn_max_lifetime = 14400
```

#### 数据库性能调优

```sql
-- 创建索引优化查询性能
CREATE INDEX idx_dashboard_org_id ON dashboard(org_id);
CREATE INDEX idx_data_source_org_id ON data_source(org_id);
CREATE INDEX idx_alert_rule_org_id ON alert_rule(org_id);

-- 定期清理旧数据
DELETE FROM alert_instance WHERE current_timestamp - triggered_at > INTERVAL '30 days';
DELETE FROM user_auth_token WHERE created_at < NOW() - INTERVAL '7 days';
```

### 6.3.2 缓存优化

#### 查询缓存配置

```ini
[dataproxy]
# 数据代理缓存
logging = true
timeout = 30
keep_alive_seconds = 30

# 查询结果缓存
cache_enabled = true
cache_ttl = 300  # 5分钟

[session]
# 会话缓存
provider = file
provider_config = sessions
cookie_secure = true
session_life_time = 86400
```

#### Redis缓存集成

```ini
[session]
provider = redis
provider_config = addr=127.0.0.1:6379,password=your-password,db=0

[remote_cache]
# 远程缓存
type = redis
connstr = addr=127.0.0.1:6379,password=your-password,db=1
```

### 6.3.3 前端性能优化

#### 资源优化配置

```ini
[server]
# 静态资源缓存
enable_gzip = true
static_root_path = public

[panels]
# 面板加载优化
enable_alpha = false
disable_sanitize_html = false

[security]
# 安全头设置
```

## 6.6 备份和恢复策略

### 6.6.1 配置备份

创建自动化备份脚本：

```bash
#!/bin/bash
# grafana-backup.sh

BACKUP_DIR="/backup/grafana"
DATE=$(date +%Y%m%d_%H%M%S)

# 创建备份目录
mkdir -p $BACKUP_DIR/$DATE

# 备份配置文件
cp -r /etc/grafana $BACKUP_DIR/$DATE/

# 备份数据库（PostgreSQL）
pg_dump -h localhost -U grafana grafana > $BACKUP_DIR/$DATE/grafana.sql

# 备份仪表板（通过API）
curl -s -H "Authorization: Bearer $API_KEY" \
  http://localhost:3000/api/search?type=dash-db \
  | jq -r '.[] | .uid' \
  | xargs -I {} curl -s -H "Authorization: Bearer $API_KEY" \
  http://localhost:3000/api/dashboards/uid/{} \
  > $BACKUP_DIR/$DATE/dashboards.json

# 压缩备份
tar -czf $BACKUP_DIR/grafana_backup_$DATE.tar.gz -C $BACKUP_DIR/$DATE .

# 清理临时文件
rm -rf $BACKUP_DIR/$DATE

# 保留最近7天的备份
find $BACKUP_DIR -name "grafana_backup_*.tar.gz" -mtime +7 -delete

echo "Backup completed: grafana_backup_$DATE.tar.gz"
```

### 6.6.2 恢复策略

创建恢复脚本：

```bash
#!/bin/bash
# grafana-restore.sh

BACKUP_FILE=$1
TEMP_DIR="/tmp/grafana_restore"

# 解压备份文件
mkdir -p $TEMP_DIR
tar -xzf $BACKUP_FILE -C $TEMP_DIR

# 停止Grafana服务
systemctl stop grafana-server

# 恢复配置文件
cp -r $TEMP_DIR/grafana/* /etc/grafana/

# 恢复数据库
psql -h localhost -U grafana grafana < $TEMP_DIR/grafana.sql

# 恢复仪表板
jq -c '.[]' $TEMP_DIR/dashboards.json | while read dashboard; do
  curl -X POST -H "Authorization: Bearer $API_KEY" \
    -H "Content-Type: application/json" \
    -d "$dashboard" \
    http://localhost:3000/api/dashboards/db
done

# 启动Grafana服务
systemctl start grafana-server

# 清理临时文件
rm -rf $TEMP_DIR

echo "Restore completed from $BACKUP_FILE"
```

## 6.7 安全最佳实践

### 6.7.1 网络安全

#### 防火墙配置

```bash
# 只允许特定IP访问Grafana
ufw allow from 10.0.0.0/8 to any port 3000
ufw allow from 192.168.1.0/24 to any port 3000
ufw deny 3000
```

#### HTTPS配置

```ini
[server]
protocol = https
http_port = 3000
cert_file = /etc/ssl/certs/grafana.crt
cert_key = /etc/ssl/private/grafana.key

# 强制HTTPS
enforce_domain = true
root_url = https://grafana.company.com/
```

### 6.7.2 访问控制

#### API密钥管理

```bash
# 创建只读API密钥
curl -X POST http://localhost:3000/api/auth/keys \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "readonly-key", "role": "Viewer"}'

# 定期轮换密钥
curl -X DELETE http://localhost:3000/api/auth/keys/1 \
  -H "Authorization: Bearer $API_KEY"
```

```hcl

  }

  config_json = file("${path.module}/dashboards/system-monitoring.json")
}

resource "grafana_alert_notification" "slack" {
  name = "Slack Alerts"
  type = "slack"
  
  settings = {
    url = var.slack_webhook_url
  }
}
```
