# 第3章：仪表板创建和面板配置

## 3.1 仪表板基础概念

仪表板是Grafana的核心功能，它允许用户将多个数据可视化组件组织在一个页面上，提供全面的监控视图。

### 3.1.1 仪表板组成元素

一个典型的Grafana仪表板包含以下元素：

```
┌─────────────────────────────────────────────────────────────┐
│                       仪表板标题                            │
├─────────────────────────────────────────────────────────────┤
│ 时间选择器 │ 刷新按钮 │ 变量选择器 │ 其他控件                │
├─────────────┼─────────┼─────────────┼────────────────────────┤
│  面板1     │  面板2  │   面板3     │         面板4          │
│  (图表)    │ (仪表)  │  (统计)     │        (表格)          │
├─────────────┼─────────┼─────────────┼────────────────────────┤
│  面板5     │  面板6  │   面板7     │         面板8          │
│ (热图)     │(日志)   │ (地图)      │       (其他)           │
└─────────────┴─────────┴─────────────┴────────────────────────┘
```

### 3.1.2 面板类型概述

Grafana支持多种面板类型，每种类型适合不同的数据展示需求：

- **时间序列图(Time series)**: 展示随时间变化的数据
- **统计面板(Stat)**: 显示单个重要数值
- **仪表盘(Gauge)**: 类似汽车仪表盘，显示范围值
- **表格(Table)**: 以表格形式展示数据
- **热图(Heatmap)**: 展示数据密度分布
- **日志面板(Logs)**: 显示日志数据
- **轨迹图(Traces)**: 分布式追踪数据

## 3.2 创建第一个仪表板

### 3.2.1 创建空白仪表板

1. **登录Grafana**: 访问http://localhost:3000
2. **创建仪表板**: 左侧菜单 → + → Dashboard
3. **添加面板**: 点击"Add new panel"
4. **选择数据源**: 选择之前配置的数据源（如Prometheus）
5. **配置查询**: 输入基础查询语句
6. **保存仪表板**: 点击右上角"Save"按钮

### 3.2.2 基础仪表板配置

创建`system-monitoring.json`配置文件示例：

```json
{
  "dashboard": {
    "id": null,
    "title": "系统监控仪表板",
    "tags": ["system", "monitoring"],
    "timezone": "browser",
    "panels": [],
    "time": {
      "from": "now-1h",
      "to": "now"
    },
    "timepicker": {},
    "templating": {
      "list": []
    },
    "refresh": "5s",
    "schemaVersion": 36,
    "version": 0,
    "uid": ""
  },
  "folderId": 0,
  "message": "Initial dashboard creation",
  "overwrite": false
}
```

## 3.3 时间序列图配置

### 3.3.1 基础时间序列图

时间序列图是最常用的面板类型，适合展示随时间变化的指标。

#### 创建CPU使用率图表

1. **添加面板**: Dashboard → Add panel
2. **选择数据源**: Prometheus
3. **配置查询**:

```promql
# CPU使用率查询
100 - (avg by (instance) (irate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)
```

4. **配置面板设置**:

```yaml
# 面板标题
Title: CPU使用率

# 可视化选项
Visualization: Time series
Draw mode: Lines
Line width: 2
Fill opacity: 10

# 坐标轴设置
Y-axis:
  Min: 0
  Max: 100
  Unit: percent

# 图例设置
Legend:
  Mode: Table
  Values: Current, Min, Max, Mean
  Placement: Bottom
```

### 3.3.2 高级时间序列配置

#### 多指标对比

在同一图表中展示多个相关指标：

```promql
# 查询A: 系统负载
node_load1

# 查询B: 内存使用率
(node_memory_MemTotal_bytes - node_memory_MemAvailable_bytes) / node_memory_MemTotal_bytes * 100

# 查询C: 磁盘使用率
(node_filesystem_size_bytes{mountpoint="/"} - node_filesystem_free_bytes{mountpoint="/"}) / node_filesystem_size_bytes{mountpoint="/"} * 100
```

#### 阈值和警报线

配置视觉警报线：

```yaml
Thresholds:
  - Value: 80
    Color: yellow
    State: warning
  - Value: 90
    Color: red
    State: alert

Thresholds mode: percentage
```

## 3.4 统计面板配置

### 3.4.1 单值统计面板

统计面板适合显示关键指标的单值，如当前QPS、错误率等。

#### 创建当前QPS统计

1. **添加面板**: Dashboard → Add panel → Stat
2. **配置查询**:

```promql
# 当前QPS
sum(rate(http_requests_total[5m]))
```

3. **配置面板设置**:

```yaml
# 显示设置
Value options:
  Stat: Value and name
  Color mode: Background
  Graph mode: Area

# 值映射
Field: Value
Calculation: Last

# 单位设置
Unit: req/sec
Decimals: 2

# 颜色阈值
Thresholds:
  - Value: 100
    Color: green
  - Value: 500
    Color: yellow
  - Value: 1000
    Color: red
```

### 3.4.2 多值统计面板

展示多个相关统计值：

```yaml
Panel:
  Type: Stat
  Options:
    Orientation: horizontal
    Text mode: value_and_name

Queries:
  - Legend: 当前用户数
    Query: sum(active_users)
    Unit: short
  
  - Legend: 今日新增
    Query: sum(new_users_today)
    Unit: short
    
  - Legend: 错误率
    Query: rate(errors_total[5m]) / rate(requests_total[5m]) * 100
    Unit: percent
    Decimals: 2
```

## 3.5 仪表盘面板配置

### 3.5.1 基础仪表盘

仪表盘面板适合显示范围值，如磁盘使用率、内存使用率等。

#### 创建磁盘使用率仪表盘

1. **添加面板**: Dashboard → Add panel → Gauge
2. **配置查询**:

```promql
# 根分区使用率
(node_filesystem_size_bytes{mountpoint="/"} - node_filesystem_free_bytes{mountpoint="/"}) / node_filesystem_size_bytes{mountpoint="/"} * 100
```

3. **配置面板设置**:

```yaml
# 仪表盘设置
Gauge:
  Mode: gauge
  Orientation: vertical
  Show: all

# 值显示
Value options:
  Show: calculated value
  Calcs: last

# 阈值配置
Thresholds:
  steps:
    - value: 0
      color: "green"
    - value: 80
      color: "yellow"
    - value: 90
      color: "red"

# 范围设置
Field: Value
Min: 0
Max: 100
Unit: percent
```

## 3.6 表格面板配置

### 3.6.1 基础表格

表格面板适合展示详细的数据列表，如服务器状态列表、错误日志等。

#### 创建服务器状态表格

1. **添加面板**: Dashboard → Add panel → Table
2. **配置查询**:

```promql
# 服务器状态查询
up
```

3. **配置表格设置**:

```yaml
# 表格样式
Table:
  Show header: true
  Rotate: false

# 列配置
Columns:
  - Field: instance
    Display: Instance
    Filterable: true
    
  - Field: job
    Display: Job
    
  - Field: Value
    Display: Status
    Custom: 
      - Mapping type: value to text
        Options:
          "1": { text: "正常", color: "green" }
          "0": { text: "异常", color: "red" }

# 排序设置
Sort by: instance
Sort order: ascending
```

### 3.6.2 高级表格配置

#### 聚合表格

展示聚合后的统计数据：

```promql
# 按实例聚合CPU使用率
avg by (instance) (irate(node_cpu_seconds_total[5m])) * 100
```

#### 表格转换

使用Transform功能增强表格显示：

```yaml
Transformations:
  - Type: organize
    Config:
      excludeByName:
        Time: true
      indexByName:
        instance: 0
        Value: 1
      renameByName:
        Value: "CPU使用率(%)"

  - Type: filter data by values
    Config:
      filters:
        - fieldName: Value
          config:
            type: range
            min: 0
            max: 100
```

## 3.7 热图面板配置

### 3.7.1 基础热图

热图适合展示数据密度分布，如请求分布、错误分布等。

#### 创建请求分布热图

1. **添加面板**: Dashboard → Add panel → Heatmap
2. **配置查询**:

```promql
# 请求延迟分布
histogram_quantile(0.95, rate(http_request_duration_seconds_bucket[5m]))
```

3. **配置热图设置**:

```yaml
# 热图选项
Heatmap:
  Data format: timeseries
  Calculation: count
  
# 颜色配置
Color:
  Mode: spectrum
  Scheme: Oranges
  Reverse: false

# 桶配置
Bucket:
  Size: 10
  Offset: 0

# 坐标轴
Y-axis:
  Decimals: 2
  Unit: s
```

## 3.8 面板布局和排列

### 3.8.1 网格布局系统

Grafana使用网格系统进行面板布局：

```yaml
Panel Layout:
  Grid Pos:
    x: 0    # 起始列 (0-23)
    y: 0    # 起始行
    w: 12   # 宽度 (1-24)
    h: 8    # 高度 (最小1)

# 示例布局配置
- CPU监控: {x:0, y:0, w:12, h:8}
- 内存监控: {x:12, y:0, w:12, h:8}
- 磁盘监控: {x:0, y:8, w:8, h:6}
- 网络监控: {x:8, y:8, w:8, h:6}
- 状态汇总: {x:16, y:8, w:8, h:6}
```

### 3.8.2 响应式布局技巧

#### 使用变量控制布局

```json
{
  "templating": {
    "list": [
      {
        "name": "panel_width",
        "type": "custom",
        "query": "12,24",
        "current": {
          "value": "12",
          "text": "12"
        }
      }
    ]
  }
}
```

#### 动态面板高度

根据数据量动态调整面板高度：

```yaml
Panel:
  Grid Pos:
    h: $__cell_0 * 2 + 4  # 基于数据行数动态计算高度
```

## 3.9 仪表板变量使用

### 3.9.1 创建变量

变量允许用户动态过滤仪表板数据。

#### 实例选择变量

1. **添加变量**: Dashboard settings → Variables → New
2. **配置变量**:

```yaml
Variable:
  Name: instance
  Type: Query
  Label: 实例
  Data source: Prometheus
  Query: label_values(up, instance)
  Refresh: On Dashboard Load
  Sort: Alphabetical (asc)
  Multi-value: true
  Include All option: true
```

#### 时间范围变量

```yaml
Variable:
  Name: time_range
  Type: Custom
  Label: 时间范围
  Query: 1h,6h,12h,24h,7d,30d
  Current: 1h
```

### 3.9.2 在查询中使用变量

在查询中引用变量：

```promql
# 使用实例变量
up{instance=~"$instance"}

# 使用时间范围变量
rate(http_requests_total[$time_range])

# 多值变量处理
up{instance=~"$instance|.+"}
```

## 3.10 仪表板共享和导出

### 3.10.1 共享仪表板

#### 生成分享链接

1. **进入分享设置**: Dashboard → Share
2. **选择分享类型**:
   - **直接链接**: 给有权限的用户
   - **快照**: 生成只读副本
   - **导出**: JSON格式导出

#### 快照配置

```yaml
Snapshot:
  Expire: 7d  # 快照过期时间
  External: false  # 是否允许外部访问
  Time range: current  # 时间范围设置
```

### 3.10.2 导出和导入

#### 导出仪表板

```bash
# 使用API导出仪表板
curl -H "Authorization: Bearer $API_KEY" \
  http://localhost:3000/api/dashboards/uid/$DASHBOARD_UID | jq .dashboard > dashboard.json
```

#### 导入仪表板

```bash
# 使用API导入仪表板
curl -X POST -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d @dashboard.json \
  http://localhost:3000/api/dashboards/db
```

## 3.11 最佳实践

### 3.11.1 设计原则

- **信息层次**: 重要指标放在显眼位置
- **颜色一致性**: 相同类型数据使用相同颜色
- **响应式设计**: 适应不同屏幕尺寸
- **性能考虑**: 避免过多面板影响加载速度

### 3.11.2 性能优化

- **查询优化**: 使用合适的查询时间范围
- **面板数量**: 控制单个仪表板的面板数量
- **缓存策略**: 合理设置刷新间隔
- **数据聚合**: 在数据源层面进行预聚合

### 3.11.3 维护策略

- **版本控制**: 将仪表板JSON纳入版本控制
- **定期审查**: 定期检查仪表板的有效性
- **文档化**: 为复杂仪表板添加说明文档
- **备份策略**: 定期备份重要仪表板
