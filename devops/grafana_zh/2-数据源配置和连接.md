# 第2章：数据源配置和连接

## 2.1 数据源概述

数据源是Grafana的核心组件，它定义了Grafana从哪里获取数据。Grafana支持多种类型的数据源，包括时序数据库、日志系统、云服务等。

### 2.1.1 支持的数据源类型

- **时序数据库**: Prometheus、InfluxDB、Graphite、TimescaleDB
- **日志系统**: Loki、Elasticsearch
- **关系数据库**: MySQL、PostgreSQL、SQL Server
- **云服务**: AWS CloudWatch、Google Cloud Monitoring、Azure Monitor
- **其他**: JSON API、CSV文件、TestData等

### 2.1.2 数据源选择原则

1. **数据类型匹配**: 根据监控数据类型选择合适的数据源
2. **性能要求**: 考虑查询性能和存储容量
3. **成本因素**: 开源vs商业，自建vs云服务
4. **生态系统**: 与现有技术栈的兼容性

## 2.2 Prometheus数据源配置

### 2.2.1 Prometheus简介

Prometheus是一个开源的系统监控和告警工具包，特别适合监控容器化环境。

#### Prometheus核心概念

- **指标(Metric)**: 监控的具体指标，如cpu_usage
- **标签(Label)**: 指标的维度信息，如instance="server1"
- **时间序列**: 指标+标签的组合，随时间变化的数据点
- **查询语言(PromQL)**: Prometheus的查询语言

### 2.2.2 安装和配置Prometheus

#### Docker方式安装

创建`prometheus.yml`配置文件：

```yaml
global:
  scrape_interval: 15s
  evaluation_interval: 15s

rule_files:
  # - "first_rules.yml"
  # - "second_rules.yml"

scrape_configs:
  - job_name: 'prometheus'
    static_configs:
      - targets: ['localhost:9090']

  - job_name: 'node_exporter'
    static_configs:
      - targets: ['node_exporter:9100']
```

创建`docker-compose-prometheus.yml`：

```yaml
version: '3.8'

services:
  prometheus:
    image: prom/prometheus:latest
    container_name: prometheus
    ports:
      - "9090:9090"
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml
      - prometheus_data:/prometheus
    command:
      - '--config.file=/etc/prometheus/prometheus.yml'
      - '--storage.tsdb.path=/prometheus'
      - '--web.console.libraries=/etc/prometheus/console_libraries'
      - '--web.console.templates=/etc/prometheus/consoles'
      - '--storage.tsdb.retention.time=200h'
      - '--web.enable-lifecycle'
    restart: unless-stopped

  node_exporter:
    image: prom/node-exporter:latest
    container_name: node_exporter
    ports:
      - "9100:9100"
    volumes:
      - /proc:/host/proc:ro
      - /sys:/host/sys:ro
      - /:/rootfs:ro
    command:
      - '--path.procfs=/host/proc'
      - '--path.sysfs=/host/sys'
      - '--collector.filesystem.mount-points-exclude=^/(sys|proc|dev|host|etc)($$|/)'
    restart: unless-stopped

volumes:
  prometheus_data:
```

启动Prometheus：

```bash
# 启动服务
docker-compose -f docker-compose-prometheus.yml up -d

# 验证服务
curl http://localhost:9090/api/v1/query?query=up
```

### 2.2.3 在Grafana中配置Prometheus数据源

1. **登录Grafana**: 访问http://localhost:3000
2. **进入数据源配置**: 左侧菜单 → Configuration → Data Sources
3. **添加数据源**: 点击"Add data source"
4. **选择Prometheus**: 在列表中选择Prometheus
5. **配置连接参数**:

```yaml
# 基本配置
Name: Prometheus
URL: http://prometheus:9090
Access: Server (Default)

# 高级配置
Scrape interval: 15s
Query timeout: 60s
HTTP Method: GET

# 认证配置（如果需要）
Basic Auth: false
With Credentials: false
TLS/SSL: Skip TLS Verify (开发环境)
```

6. **测试连接**: 点击"Save & Test"，应该显示"Data source is working"

### 2.2.4 PromQL查询示例

在Grafana中使用PromQL查询数据：

```promql
# 基础查询
up
node_memory_MemAvailable_bytes

# 带标签的查询
node_cpu_seconds_total{mode="idle"}

# 聚合查询
sum(rate(node_cpu_seconds_total[5m])) by (mode)

# 数学运算
100 - (avg(irate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)
```

## 2.3 InfluxDB数据源配置

### 2.3.1 InfluxDB简介

InfluxDB是一个专门为时序数据设计的数据库，具有高性能的写入和查询能力。

#### InfluxDB核心概念

- **数据库(Database)**: 数据的逻辑容器
- **测量(Measurement)**: 类似SQL中的表
- **标签(Tag)**: 索引字段，用于快速查询
- **字段(Field)**: 实际存储的数值数据
- **时间戳(Timestamp)**: 数据点的时间

### 2.3.2 安装和配置InfluxDB

#### Docker方式安装

创建`docker-compose-influxdb.yml`：

```yaml
version: '3.8'

services:
  influxdb:
    image: influxdb:latest
    container_name: influxdb
    ports:
      - "8086:8086"
    environment:
      - DOCKER_INFLUXDB_INIT_MODE=setup
      - DOCKER_INFLUXDB_INIT_USERNAME=admin
      - DOCKER_INFLUXDB_INIT_PASSWORD=admin123
      - DOCKER_INFLUXDB_INIT_ORG=myorg
      - DOCKER_INFLUXDB_INIT_BUCKET=mybucket
      - DOCKER_INFLUXDB_INIT_ADMIN_TOKEN=mytoken
    volumes:
      - influxdb_data:/var/lib/influxdb2
    restart: unless-stopped

volumes:
  influxdb_data:
```

启动InfluxDB：

```bash
# 启动服务
docker-compose -f docker-compose-influxdb.yml up -d

# 验证服务
curl http://localhost:8086/health
```

#### 写入测试数据

使用InfluxDB CLI写入测试数据：

```bash
# 进入容器
docker exec -it influxdb influx

# 写入测试数据
insert cpu,host=server01,region=us-west usage=0.64,idle=0.36
insert cpu,host=server02,region=us-east usage=0.78,idle=0.22
insert memory,host=server01,region=us-west used=8,free=16
insert memory,host=server02,region=us-east used=12,free=12
```

### 2.3.3 在Grafana中配置InfluxDB数据源

1. **添加数据源**: Configuration → Data Sources → Add data source
2. **选择InfluxDB**: 在列表中选择InfluxDB
3. **配置连接参数**:

```yaml
# 基本配置
Name: InfluxDB
Query Language: Flux (推荐) 或 InfluxQL
URL: http://influxdb:8086

# 认证配置
Organization: myorg
Token: mytoken
Default Bucket: mybucket

# 高级配置
Max series: 1000
Timeout: 60s
```

4. **测试连接**: 点击"Save & Test"

### 2.3.4 Flux查询示例

在Grafana中使用Flux查询数据：

```flux
// 基础查询
from(bucket: "mybucket")
  |> range(start: -1h)
  |> filter(fn: (r) => r._measurement == "cpu")
  |> filter(fn: (r) => r._field == "usage")

// 聚合查询
from(bucket: "mybucket")
  |> range(start: -1h)
  |> filter(fn: (r) => r._measurement == "cpu")
  |> filter(fn: (r) => r._field == "usage")
  |> aggregateWindow(every: 1m, fn: mean)

// 多字段查询
from(bucket: "mybucket")
  |> range(start: -1h)
  |> filter(fn: (r) => r._measurement == "cpu")
  |> filter(fn: (r) => r._field == "usage" or r._field == "idle")
```

## 2.4 MySQL数据源配置

### 2.4.1 MySQL数据源特点

- 适合存储业务指标数据
- 支持复杂的SQL查询
- 可以连接现有的业务数据库
- 支持事务性数据

### 2.4.2 安装和配置MySQL

#### Docker方式安装

创建`docker-compose-mysql.yml`：

```yaml
version: '3.8'

services:
  mysql:
    image: mysql:8.0
    container_name: mysql
    ports:
      - "3306:3306"
    environment:
      - MYSQL_ROOT_PASSWORD=root123
      - MYSQL_DATABASE=monitoring
      - MYSQL_USER=grafana
      - MYSQL_PASSWORD=grafana123
    volumes:
      - mysql_data:/var/lib/mysql
    restart: unless-stopped

volumes:
  mysql_data:
```

启动MySQL：

```bash
# 启动服务
docker-compose -f docker-compose-mysql.yml up -d

# 验证服务
docker exec -it mysql mysql -u root -proot123 -e "SHOW DATABASES;"
```

#### 创建测试数据

```sql
-- 创建监控数据表
CREATE TABLE metrics (
    id INT AUTO_INCREMENT PRIMARY KEY,
    metric_name VARCHAR(100) NOT NULL,
    metric_value DECIMAL(10,4) NOT NULL,
    tags JSON,
    timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 插入测试数据
INSERT INTO metrics (metric_name, metric_value, tags) VALUES
('cpu_usage', 0.75, '{"host": "server01", "region": "us-west"}'),
('memory_usage', 0.68, '{"host": "server01", "region": "us-west"}'),
('cpu_usage', 0.82, '{"host": "server02", "region": "us-east"}'),
('memory_usage', 0.72, '{"host": "server02", "region": "us-east"}'),
('disk_usage', 0.45, '{"host": "server01", "region": "us-west"}'),
('disk_usage', 0.38, '{"host": "server02", "region": "us-east"}');

-- 创建时间序列数据
INSERT INTO metrics (metric_name, metric_value, tags, timestamp) VALUES
('requests_per_second', 150.5, '{"service": "api", "env": "prod"}', NOW() - INTERVAL 5 MINUTE),
('requests_per_second', 148.2, '{"service": "api", "env": "prod"}', NOW() - INTERVAL 4 MINUTE),
('requests_per_second', 152.8, '{"service": "api", "env": "prod"}', NOW() - INTERVAL 3 MINUTE),
('requests_per_second', 149.1, '{"service": "api", "env": "prod"}', NOW() - INTERVAL 2 MINUTE),
('requests_per_second', 151.3, '{"service": "api", "env": "prod"}', NOW() - INTERVAL 1 MINUTE);
```

### 2.4.3 在Grafana中配置MySQL数据源

1. **添加数据源**: Configuration → Data Sources → Add data source
2. **选择MySQL**: 在列表中选择MySQL
3. **配置连接参数**:

```yaml
# 基本配置
Name: MySQL
Host: mysql:3306
Database: monitoring
User: grafana
Password: grafana123

# 高级配置
Max open connections: 100
Max idle connections: 100
Connection max lifetime: 14400

# TLS/SSL配置
TLS/SSL Mode: Disabled (开发环境)
```

4. **测试连接**: 点击"Save & Test"

### 2.4.4 SQL查询示例

在Grafana中使用SQL查询数据：

```sql
-- 基础查询
SELECT timestamp, metric_value 
FROM metrics 
WHERE metric_name = 'cpu_usage' 
ORDER BY timestamp DESC

-- 带标签过滤的查询
SELECT timestamp, metric_value 
FROM metrics 
WHERE metric_name = 'cpu_usage' 
AND JSON_EXTRACT(tags, '$.host') = 'server01'
ORDER BY timestamp DESC

-- 时间范围查询
SELECT timestamp, metric_value 
FROM metrics 
WHERE metric_name = 'requests_per_second' 
AND timestamp >= DATE_SUB(NOW(), INTERVAL 1 HOUR)
ORDER BY timestamp ASC

-- 聚合查询
SELECT 
    DATE(timestamp) as date,
    AVG(metric_value) as avg_usage
FROM metrics 
WHERE metric_name = 'cpu_usage'
GROUP BY DATE(timestamp)
ORDER BY date DESC
```

## 2.5 测试数据源配置

### 2.5.1 使用TestData数据源

Grafana内置了TestData数据源，用于测试和演示。

#### 配置TestData数据源

1. **添加数据源**: Configuration → Data Sources → Add data source
2. **选择TestData**: 在列表中选择TestData DB
3. **配置参数**:

```yaml
Name: TestData
Type: TestData DB
```

4. **保存配置**: 无需特殊配置，直接保存

#### 使用TestData生成测试数据

在仪表板中使用TestData：

1. **添加面板**: + Add panel
2. **选择数据源**: 选择TestData
3. **选择场景**: 有多种预定义场景
   - Random Walk: 随机游走数据
   - CSV Content: CSV格式数据
   - Predictable Pulse: 可预测的脉冲数据
   - USA generated data: 美国相关数据

### 2.5.2 数据源验证脚本

创建验证脚本来测试所有数据源：

```bash
#!/bin/bash
# datasource-test.sh

echo "=== Testing Data Sources ==="

# 测试Prometheus
echo "Testing Prometheus..."
curl -s http://localhost:9090/api/v1/query?query=up | jq '.data.result[0].value[1]' | grep -q "1" && echo "✓ Prometheus OK" || echo "✗ Prometheus Failed"

# 测试InfluxDB
echo "Testing InfluxDB..."
curl -s http://localhost:8086/health | jq '.status' | grep -q "pass" && echo "✓ InfluxDB OK" || echo "✗ InfluxDB Failed"

# 测试MySQL
echo "Testing MySQL..."
docker exec mysql mysql -u grafana -pgrafana123 -e "SELECT 1;" monitoring > /dev/null 2>&1 && echo "✓ MySQL OK" || echo "✗ MySQL Failed"

echo "=== Data Source Test Complete ==="
```

## 2.6 数据源管理最佳实践

### 2.6.1 配置管理

- **使用环境变量**: 避免硬编码敏感信息
- **版本控制**: 将配置文件纳入版本控制
- **备份策略**: 定期备份数据源配置

### 2.6.2 性能优化

- **连接池配置**: 合理设置连接数
- **查询优化**: 使用索引和合适的查询语句
- **缓存策略**: 利用Grafana的查询缓存

### 2.6.3 安全考虑

- **最小权限原则**: 数据源用户只授予必要权限
- **网络隔离**: 生产环境使用内部网络
- **TLS加密**: 启用传输层加密

## 2.7 故障排除

### 2.7.1 常见问题

#### 连接超时

```bash
# 检查网络连通性
ping <datasource_host>

# 检查端口是否开放
telnet <datasource_host> <port>

# 检查防火墙规则
sudo ufw status
```

#### 认证失败

- 检查用户名/密码是否正确
- 验证权限设置
- 检查Token是否过期

#### 查询性能问题

- 优化查询语句
- 检查数据源负载
- 调整查询超时时间

### 2.7.2 调试工具

1. **进入Explore**: 左侧菜单 → Explore
